# Практика 02

Консольная программа на Java с меню и обработкой ошибок ввода.

## Что реализовано

- сумма ряда `1 + 1/2 + ... + 1/N`;
- все целые степени числа `A` от `1` до `N`;
- проверка наличия нечётных цифр в числе `N`;
- расстояние между двумя точками.

Меню работает в цикле, ввод проверяется, расчёты вынесены в отдельные
статические методы.

## Запуск

Точка входа — `org.example.Main` в папке `src/main/java`.
