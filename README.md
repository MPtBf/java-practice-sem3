# Практики по программированию

Учебный репозиторий по дисциплине «Современные языки программирования».
Проекты выполнены на Java 21 и собраны с помощью Maven.

## Список практик

| Практика | Тема | Материалы |
|---|---|---|
| 01 | Командная разработка | Выполнялась в команде в отдельном проекте, поэтому в этом репозитории её папки нет. |
| 02 | Консольная программа с меню и обработкой ошибок | [README](practice-02/README.md) |
| 03 | Работа с массивами и матрицами | [README](practice-03/README.md) |
| 04 | Объектно-ориентированное программирование | [README](practice-04/README.md) |

## Кратко о работах

- **Практика 02** — консольные расчёты: сумма ряда, степени числа,
  проверка нечётных цифр и расстояние между точками. Есть меню, проверка
  ввода и разделение вычислений на статические методы.
- **Практика 03** — задачи на массивы и матрицы: вывод элементов по чётным
  и нечётным индексам, поиск монотонно убывающих участков, поэлементный
  максимум двух массивов и построчный вывод матрицы в разном направлении.
- **Практика 04** — ООП: класс `IntList`, иерархия задач `Task` с
  наследниками, иерархия расчётов `Calculation`, а также JUnit 5-тесты.
