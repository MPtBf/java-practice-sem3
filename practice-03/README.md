# Практика 03

Задачи на массивы и матрицы.

## Что реализовано

- вывод сначала элементов с чётными индексами, затем с нечётными;
- подсчёт участков монотонного убывания массива;
- поэлементный максимум двух массивов;
- вывод матрицы с чередованием направления строк.

## Запуск

Точка входа — `org.example.Main` в папке `src/main/java`.
